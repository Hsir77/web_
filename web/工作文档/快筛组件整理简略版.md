## 2. 状态管理系统（字符串 ↔ Map）🔁
### 2.1 概述
快筛的选中项同时使用两种格式：
- 字符串格式：`"packageGroupPeopleNums:8,vehicleModelAndSeats:7;18"`
- Map 格式（内部计算）：
```js
Map {
  'packageGroupPeopleNums' => [ '8' ],
  'vehicleModelAndSeats' => [ '7', '18' ]
}
```

### 2.2 双向转换函数（interactLogic.ts）
- `selectedItemsParse(str: string, minPrice?, maxPrice?)`（行30-48）
  - 将字符串按 `,` 分割，再按 `:` 分成 key / val，val 再按 `;` 分成数组，最后设置 Map。
  - 示例输入：`"packageGroupPeopleNums:8,vehicleModelAndSeats:7;18,priceRange:100;500"`
  - 输出示例：Map { packageGroupPeopleNums => ['8'], vehicleModelAndSeats => ['7','18'], priceRange => ['100','500'] }

- `selectedItemsParseReverse(map: Map)`（行54-61）
  - 将 Map 转回字符串，形如 `${key}:${values.join(';')},`，最后去掉末尾逗号。

### 2.3 核心更新函数：`updateSelectedItems()`（interactLogic.ts 行101-280）
功能：根据用户点击或下拉选项，计算并返回新的选中项字符串。
备注参数（部分）：
```ts
updateSelectedItems(
  filterOptions: FilterOption[], // 所有筛选选项
  currentIndex: number,
  selectedItems: string | Map,
  type: CommonGroupType,
  data: Array<number> | boolean | string,
  isArrayIndex = true,
  bundleData: Array<any> = [],
  forceSingleSelection = false
): string
```
处理流程要点：
- 将输入的 `selectedItems` 统一转成 Map 操作
- 获取 `currentFilterOption = filterOptions[currentIndex]`
- 根据 `type`（见下文 `CommonGroupType`）选择具体逻辑：
  - SELF_LEVEL_ONE（布尔型）：切换选中 / 删除
  - SELF_LEVEL_TWO（数组索引）：根据 `sortItemModelList` 映射为 idStr
  - LINK_LEVEL_ONE（联动一级）：删除关联的二级选中项等
- 单选 / 多选逻辑：如果 `forceSingleSelection` 或特定字段需要单选，则替换为单个值；否则追加
- 返回字符串：调用 `selectedItemsParseReverse(updatedMap)`

## 4. 用户交互 - 点击快筛项 🖱️
### 4.1 点击处理（行836-953）
交互流程：
1. `onItemPress(indexArray, index)` 被调用
2. 前置检查：
   - 如果面板已关闭，调用 `handalPanelOpened()` 通知父组件
   - `toggleGroupIndexArray.current = indexArray`；`setToggleGroupIndex(index)`
3. 面板开闭逻辑：
   - 识别当前类型 `currentType = getCommonGroupType(quickFilterOptions, index)`
   - 如果是一级项（`SELF_LEVEL_ONE` / `LINK_LEVEL_ONE`），直接更新并关闭面板；否则打开或切换下拉面板可见性
4. 埋点：调用 `lxMC({...})` 上报点击事件
5. 处理 `exclude` 互斥关系：如果新选项与某些已选项互斥，需要清理对应 `activeArray`
6. 一级项点击示例：
```js
const idStr = quickFilterOptions[index].sortItemModelList[0].idStr;
const _updatedSelectedItems = updateSelectedItems(...);
setGlobalSelectedItems(_updatedSelectedItems);
if (currentType === LINK_LEVEL_ONE) newLinkLogic(_updatedSelectedItems);
```

### 4.2 示例（“一日游”快速切换）
- 用户点击“一日游” → `getCommonGroupType(...)` 返回 `SELF_LEVEL_ONE`
- `updateSelectedItems(...)` 解析并切换 Map 后转字符串，最终 `globalselectedItems` 变为 `"packageGroupPeopleNums:8,singleDayTour:true"`
- `useEffect` 触发：重新渲染快筛栏、回调父组件、调用 `newLinkLogic()` 更新联动

## 5. 下拉面板（DropDownPanel）📥
### 5.1 作用与 Props（行1084-1110）
- `contentType`：当前选中的筛选类型
- `dropDownSelectInfo`：{ selectedTeamSize, selectedVehicleLevel, selectedDepartCities }
- `filterSelectedItems`：完整的选中项字符串
- `onFilterSelectedItemsChanged`：选中项变化回调
- `quickFilterOptions`：所有筛选项配置

### 5.2 Panel 内部结构
- Filter 组件（目的地搜索 / 分类筛选 / 排序 / 确认取消）
- VehicleLevelToggleGroup（小车 / 大巴）
- DepartCitiesToggleGroup（城市列表）
- TeamSizeToggleGroup（人数列表）
- Price（滑块）与 PriceCalendarSelector（日历）

### 5.3 面板数据流
1. 用户在面板中选择人数 → `setDropDownSelectInfo({ selectedTeamSize: [...] })`
2. 面板调用 `onFilterSelectedItemsChanged`（回调父组件）
3. 父组件 `onCommonGroupUpdateHandler` 调用 `setGlobalSelectedItems(newValue)` → `globalselectedItems` 更新
4. 其他 Effects 依赖 `globalselectedItems`，触发快筛栏渲染 / 联动 / 父组件回调

## 阶段 5：下拉面板（DropDownPanel）

作用：
- 当用户点击二级项（例如“出发地参团”、“人数/车型/城市”中的某项）时，弹出下拉面板用于详细选择。

核心 Props（示例，行号约 1084-1110）：
- `contentType`：当前选中的筛选类型
- `dropDownSelectInfo`：{ selectedTeamSize, selectedVehicleLevel, selectedDepartCities }
- `filterSelectedItems`：`globalselectedItems`（完整的选中项字符串）
- `onFilterSelectedItemsChanged`：选中项变化的回调
- `quickFilterOptions`：所有筛选项配置

内部结构（简要）：
- `Filter` 组件（详细筛选面板）
  - 目的地搜索、分类筛选、排序、确认/取消 等
- `VehicleLevelToggleGroup`（车型选择）
  - 小车列表 / 大巴列表
- `DepartCitiesToggleGroup`（出发城市选择）
- `TeamSizeToggleGroup`（人数选择）
- `PriceCalendarSelector`（日期选择）
- `Slide`（价格滑块）

数据流（示例）：
1. 用户在 DropDownPanel 中选择人数 → `setDropDownSelectInfo({ selectedTeamSize: [8] })`
2. DropDownPanel 触发 `onFilterSelectedItemsChanged`
3. 父组件 `FilterQuick` 的 `onCommonGroupUpdateHandler` 处理并调用 `setGlobalSelectedItems(newValue)`
4. `globalselectedItems` 变化会触发：
   - 快筛栏重新渲染

## `newLinkLogic()`（联动逻辑，约行 959-975）
```typescript
const newLinkLogic = (_updatedSelectedItems: string) => {
  const updatedSelectedMap = selectedItemsParse(_updatedSelectedItems, minPrice, maxPrice);

  setDropDownSelectInfo({
    selectedTeamSize:
      updatedSelectedMap?.get?.(QuickFilterItem.TEAM_SIZE)?.map?.(item => Number(item)) || [],
    selectedVehicleLevel:
      updatedSelectedMap?.get?.(QuickFilterItem.VEHICLE_LEVEL)?.map?.(item => Number(item)) || [],
    selectedDepartCities:
      updatedSelectedMap?.get?.(QuickFilterItem.DEPART_CITIES)?.map?.(item => Number(item)) || [],
  });
};
```

执行时机：当 `globalselectedItems` 变化时调用，负责将字符串格式的选中状态同步到 `dropDownSelectInfo`，保持面板与全局状态一致。

### 2.1 分栏式架构

FilterQuick 采用模块化分栏式架构，将不同职责清晰分离：

```
FilterQuick（快筛主容器）
├─ UI 层
│   ├─ ScrollView（水平滚动容器）
│   └─ ToggleGroup（快筛项容器）
│       ├─ 快筛项渲染（8+种类型）
│       └─ Image（右侧渐变蒙层）
├─ 交互层
│   ├─ DropDownPanel（模态下拉面板）
│   │   ├─ Price 滑块
│   │   ├─ Calendar 日期
│   │   ├─ Filter 分类
│   │   ├─ Sort 排序
│   │   └─ Tabs（人数 / 车型 / 城市）
│   └─ onItemPress（快筛项点击处理）
├─ 状态层
│   ├─ globalselectedItems（下拉选择字符串）
│   ├─ dropDownSelectInfo（下拉筛选信息）
│   ├─ activeArray（活跃筛选项索引）
│   └─ toggleGroupIndex（当前展开的筛选项）
├─ 逻辑层
│   ├─ newLinkLogic（联动更新逻辑）
│   ├─ updateSelectedItems（选项更新）
│   ├─ getCommonGroupType（分组类型识别）
```

#### 3.1.2 筛选类型的三大分组

FilterQuick 将筛选项分为三大类，每类有不同的交互模式：

```ts
// src/utils/QuickFilterUtils.ts
enum CommonGroupType {
  SELF_LEVEL_ONE = "SELF_LEVEL_ONE",   // 自包含的一级项（单选）
  LINK_LEVEL_ONE = "LINK_LEVEL_ONE",   // 联动一级项（与其他项联动）
  DROPDOWN = "DROPDOWN",               // 下拉框类型（需打开面板）
}
```

- **类型 1：自包含一级项（SELF_LEVEL_ONE）**
  - 这类项目在快筛栏直接显示，点击即可选择，不需打开下拉面板。
  - 示例：目的地、主题等
    ```js
    { sortItemField: "destId", sortItemName: "热门目的地", sortItemType: "normal", sortItemModeList: [ { idStr: "1", name: "北京" }, { idStr: "2", name: "上海" }, ... ] }
    // 快筛项呈现： [北京] [上海] [杭州] ...
    ```
  - 特点：
    - 直接在快筛栏显示选项
    - 点击切换选中 / 未选中状态
    - 通过 updateSelectedItems 直接更新状态

- **类型 2：联动一级项（LINK_LEVEL_ONE）**
  - 这类项目会与其他筛选项形成联动关系，选择后会影响其他项的可用性。
  - 示例：旅行天数
    ```js
    { sortItemField: "travelDays", sortItemName: "旅行天数", sortItemType: "order", subSortItemList: [ { sortItemField: "travelDays", sortItemModeList: [...] }, { sortItemField: "travelNights", sortItemModeList: [...] } ] }
    // 选择 “3 天 2 晚” 后，其他筛选项会自动过滤相关内容
    ```
  - 特点：
    - 支持多级嵌套结构（subSortItemList）
    - 会触发联动更新逻辑
    - 通过 newLinkLogic 处理联动

- **类型 3：下拉面板类型（DROPDOWN）**
  - 这类项目需要打开模态下拉面板才能进行详细选择。
  - 示例：价格范围
    ```js
    { sortItemField: "priceRange", sortItemName: "价格", sortItemType: "order", sortItemShowType: 1 } // 1 = 下拉面板展示
    // 点击 “价格” → 打开下拉面板 → 使用滑块选择 → 确认更新
    ```
  - 特点：
    - 打开 DropDownPanel 进行详细交互
    - 支持复杂的 UI 交互（滑块、日历、多选等）
    - 面板关闭时才更新状态

### 8.1 联动筛选的工作原理

#### 8.1.1 什么是联动筛选？

某个筛选项的选择会影响其他筛选项的可用选项。

例如：

```
用户选择 “旅行天数：3 天 2 晚”
├─ 出发城市：自动过滤只包含 3 天 2 晚的出发点
├─ 价格范围：自动调整为 3 天 2 晚产品的价格范围
└─ 其他相关筛选项：相应更新
```

## 8.3 通用联动逻辑（newLinkLogic）
关键代码位置：`index.tsx`（约 595-610 行）
```typescript
/**
 * 将更新后的选中字符串解析并同步到三个下拉项的状态

const newLinkLogic = (_updatedSelectedItems: string) => {
  const updatedSelectedMap = selectedItemsParse(_updatedSelectedItems);

  setDropDownSelectInfo({
    selectedTeamSize:
      updatedSelectedMap?.get?.(QuickFilterItem.TEAM_SIZE)?.map?.(item => Number(item)) || [],
    selectedVehicleLevel:
      updatedSelectedMap?.get?.(QuickFilterItem.VEHICLE_LEVEL)?.map?.(item => Number(item)) || [],
    selectedDepartCities:
      updatedSelectedMap?.get?.(QuickFilterItem.DEPART_CITIES)?.map?.(item => Number(item)) || [],
  });
};
```
作用：当某些通用（非特殊）筛选项发生变化（例如旅行天数、价格区间等）时，解析新状态并自动更新三个特殊下拉项的当前选择，保证 UI 与内部状态一致。
