## 1. 组件概述

**DropDownPanel** 是美团集团游快速筛选系统的核心模态下拉面板组件。

**核心职责：**
- 显示不同类型的筛选选项（价格、人数、车型、城市、日期等）
- 捕获用户交互，更新筛选状态
- 将用户选择发送给父组件进行页面筛选
- 管理复杂的状态同步逻辑
- 采集埋点数据用于数据分析

**使用场景示例：**

```jsx
<DropDownPanel
  showModalHeight={100}
  contentType="priceRange"               // 显示价格筛选
  dropDownSelectInfo={dropDownInfo}     // 传入下拉数据
  setDropDownSelectInfo={setDropDownInfo}
  onFilterSelectedItemsChanged={onUpdate} // 确认时通知父组件
  quickFilterOptions={filterOptions}
  // ... 其他 props
/>
```

## 2. 单列 vs 双列布局

### 2.1 单列 / 双列定义

在美团集团游中有两种货架展示方式：
- **单列货架**：传统的竖向排列产品展示
- **双列货架**：两列并排展示产品（宽屏更充分利用空间）

## 3. 完整数据流向


### 3.1 整体流程图

**初始化阶段（用户打开面板）**

```
setShowModalVisible(true)
↓
触发 useEffect（监听 showModalVisible）
↓
selectedItemsParse(filterSelectedItems)
↓
setSelectedMap(解析后的Map)
↓
setSelectedDateArray(日期)
```

**用户交互阶段（选择筛选选项）**

```
价格 → onSlideChange → setPriceValue → selectedMap.set("priceRange", [...])
人数 → onCrowdNum → setCrowd → selectedMap.set(...)
日期 → onCalendarSelect → setSelectedDate → selectedMap.set(...)
车型/城市/人数 → onTeamSizeSelect → setTeamSizeArray → selectedMap.set(...)
```

**确认阶段（用户点击确认）**

```
onConfirmPress()
↓
根据 contentType 进行特定处理（switch(contentType)）
  TEAM_SIZE → 更新 dropDownSelectInfo
  PRICE_RANGE → 更新 selectedMap 并生成字符串
  DEPART_CITIES → 更新 dropDownSelectInfo
  VEHICLE_LEVEL → 更新 dropDownSelectInfo
↓
selectedItemsParseReverse()（将 Map 转换回字符串格式）
  例如："priceRange:100-5000,packageGroupPeopleNums:8;10"
↓
onFilterSelectedItemsChanged(字符串)（通知父组件，父组件发起新查询）
↓
setShowModalVisible(false)（关闭面板）
↓
props.onPanelClose?.("confirm")（告诉父组件面板已关闭）
```

### 3.2 字符串格式详解


**输入格式示例：**

```
priceRange:100-5000,packageGroupPeopleNums:8;10,vehicleModelAndSeats:1;4
```

**解析后的 Map 结构：**

```
Map {
  "priceRange" → ["100", "5000"],
  "packageGroupPeopleNums" → ["8", "10"],
  "vehicleModelAndSeats" → ["1", "4", "13"],
  "departCities" → ["1", "2"]
}
```

**转换规则：**
- 不同筛选项用 `,` 分隔
- 同一筛选项的多个值用 `;` 分隔
- 格式：`fieldName:value1;value2;value3`

### 3.3 核心转换函数

```ts
// 文件：filter-common/utils/tools.ts

// 字符串 → Map
function selectedItemsParse(filterSelectedItems: string, minPrice, maxPrice) {
  const map = new Map();
  const items = filterSelectedItems.split(',');
  items.forEach(item => {
    const [key, values] = item.split(':');
    map.set(key, values.split(';'));
  });
  return map;
}

// Map → 字符串
function selectedItemsParseReverse(map, minPrice, maxPrice) {
  const items = [];
  map.forEach((values, key) => {
    if (values.length > 0) {
      items.push(`${key}:${values.join(';')}`);
    }
  });
  return items.join(',');
}
```

**5. 核心状态变量**

**5.1 状态变量全景**

| 变量名 | 类型 | 用途 |
| --- | --- | --- |
| selectedMap | Map<string, any[]> | 中枢：存储所有筛选项的选中值 |
| selectedItemInner | number[] | 通用筛选项的选中索引数组 |
| teamSizeActiveArray | number[] | 团队人数的选中项索引 |
| carActiveArray | number[] | 小车类型的选中项索引 |
| busActiveArray | number[] | 大巴类型的选中项索引 |
| departCitiesActiveArray | number[] | 出发城市的选中项索引 |
| priceValue | number[] | 价格范围 [min, max] |
| crowdNumSelected | Array<{value, indexKey}> | 人数选择 [成人, 儿童] |
| selectedDateArray | string[] | 出发 / 到达日期 [startDate, endDate] |
| showModalVisible | boolean | 控制面板显示 / 隐藏 |
| dropDownSelectInfo | 对象 | 固定筛选项的数据（车型、人数、城市） |

**5.2 selectedMap 深度解析**

这是最核心的状态，是所有筛选项的真实记录：

```ts

// - 选择车型：小车和大巴
// - 选择城市：北京、上海

  "priceRange" → ["100", "5000"],

  "vehicleModelAndSeats" → ["1", "4", "13"],
  "departCities" → ["1", "2"],
  "startDate" → ["2024-01-15"],

**5.3 状态变量的关系**

```
selectedMap（主状态）
├─ 固定筛选项（车型/人数/城市等）→ dropDownSelectInfo
├─ 通用项 → selectedItemInner
└─ 特殊项（价格/日期/人数等）→ 其他状态变量（priceValue等）
```

**5.4 状态同步关键点**

两条数据流：

> 新方案（推荐）：基于 selectedMap 的通用方案

```ts
// 所有筛选项都存在 selectedMap 中
_selectedMap.set("priceRange", ["100", "5000"]);
_selectedMap.set("packageGroupPeopleNums", ["8"]);
// 最后转换为字符串传给父组件
```

> 旧方案（兼容）：基于 dropDownSelectInfo 的特定方案

```ts
// 只用于车型、人数、城市这3个固定筛选项
setDropDownSelectInfo({
  selectedTeamSize: [8, 10],
  selectedVehicleLevel: [1, 4, 13],
  selectedDepartCities: [1, 2]
})
```

为什么需要两条流？
- 旧项目可能已有 dropDownSelectInfo 的依赖
- 新项目使用 selectedMap 的通用方案
- 两者并存实现平滑迁移

**6.1 打开面板流程**

**6.2 用户交互流程（以价格为例）**

```ts
// 用户在滑块上拖动

// 步骤 1: 滑块组件触发 onChange 事件
<Slide onChange={changePriceValue} />

// 步骤 2: 回调函数更新本地价格状态
const changePriceValue = (min: number, max: number) => {
  setPriceValue([min, max]); // 这是为了界面实时显示价格
};

// 步骤 3: 用户点击确认按钮
<Footer onConfirm={onConfirmPress} />

// 步骤 4: 确认回调处理价格数据
const onConfirmPress = (e: any, sMap?: Map<any, any>) => {
  const _selectedMap = sMap || new Map(selectedMap);
  // ...
  switch (props.contentType) {
    case QuickFilterItem.PRICE_RANGE:
      // 将价格数据放入 selectedMap
      _selectedMap.set(
        "priceRange",
        priceValue?.map?.(item => String(item)) ?? []
      );
      setSelectedMap(_selectedMap);

      // 将 selectedMap 和其他筛选项合并
      const mergedMap = mergeMaps(
        getDropDownSelectInfoMap(),  // 车型、人数、城市
        _selectedMap                 // 价格、日期等
      );

      // 转换回字符串
      const finalString = selectedItemsParseReverseFilter(
        mergedMap, minPrice, maxPrice
      );

      // 通知父组件
      onFilterSelectedItemsChanged(finalString);
      break;
  }

  // 关闭面板
  setShowModalVisible(false);
  props.onPanelClose?.("confirm");
};
```

**6.3 清空筛选流程**

```ts
const onClearPress = () => {
  // 步骤 1: 创建 selectedMap 的副本
  const _selectedMap = new Map(selectedMap);

  // 步骤 2: 找到当前打开的筛选项配置
  const currentQuickFilter = quickFilterOptions?.find(
    (quick) => quick.sortItemField === props.contentType
  );

  // 步骤 3: 处理带子筛选项的情况（如天数、晚数、日期）
  if (currentQuickFilter?.subSortItemList) {
    currentQuickFilter.subSortItemList.forEach(
      (subOption: { sortItemField: string }) => {
        // 支持多个字段（用逗号分隔）
        if (subOption?.sortItemField?.split(",").length > 1) {
          subOption.sortItemField
            ?.split(",")
            ?.forEach?.((item: string) => {
              _selectedMap.set(item, []); // 清空
            });
        } else {
          _selectedMap.set(subOption.sortItemField, []);
        }
      }
    );
  }

  // 步骤 4: 根据筛选项类型调用对应的清空方法
  switch (currentQuickFilter?.sortItemField) {
    case QuickFilterItem.TEAM_SIZE:
      setTeamSizeActiveArray([]);
      break;
    case QuickFilterItem.VEHICLE_LEVEL:
      setCarActiveArray([]);
      setBusActiveArray([]);
      break;
    case QuickFilterItem.DEPART_CITIES:
      setDepartCitiesActiveArray([]);
      break;
    case QuickFilterItem.PRICE_RANGE:
      setPriceValue([]);
      slideRef?.current?.reset?.(0, maxPrice ?? 5000); // 重置滑块
      break;
    case QuickFilterItem.CROWD_NUM:
      crowdNumSelectedRef?.current?.onPressClean?.();
      break;
    default:
      setSelectedItemInner([]);
      break;
  }

  // 步骤 5: 埋点记录用户清空操作
  if (lxParams?.cid && lxParams?.pageInfoKey) {
    lx.lxModuleClick({
      cid: lxParams.cid,
      bid: lxParams?.itemCancelBid,
      param: {
        select_content: currentQuickFilter?.sortItemField,
      },
    });
  }
};

  let _select_content = ''; // 埋点：选中内容
  let _select_count = -999; // 埋点：选中数量

  // 获取要使用的 selectedMap（来自参数或使用当前状态）
  const _selectedMap = sMap || new Map(selectedMap);

  // 根据筛选项类型分别处理
  switch (props.contentType) {
    // ========== 情况1: 团队人数 ==========
    case QuickFilterItem.TEAM_SIZE:
      // 将选中的团队人数同步到 dropDownSelectInfo
      setDropDownSelectInfo({
        selectedTeamSize: teamSizeActiveArray?.map((index) => {
          return teamSizeInfo?.[index]?.value;
        }),
        selectedVehicleLevel: dropDownSelectInfo.selectedVehicleLevel,
        selectedDepartCities: dropDownSelectInfo.selectedDepartCities,
      });

      // 组装埋点数据
      const teamSizeContent: string[] = [];
      teamSizeActiveArray?.map((index) => {
        teamSizeContent.push(
          `团队人数_${teamSizeInfo?.[index]?.text}`
        );
      });
      _select_count = teamSizeActiveArray?.length || -999;
      _select_content = teamSizeContent.join(",");
      break;

    // ========== 情况2: 车型 ==========
    case QuickFilterItem.VEHICLE_LEVEL:
      setDropDownSelectInfo({
        selectedTeamSize: dropDownSelectInfo.selectedTeamSize,
        selectedVehicleLevel: [
          ...carActiveArray?.map((index) =>
            vehicleLevelInfo?.car?.[index]?.value
          ),
          ...busActiveArray?.map((index) =>
            vehicleLevelInfo?.bus?.[index]?.value
          ),
        ],
        selectedDepartCities: dropDownSelectInfo.selectedDepartCities,
      });

      const vehicleLevelContent: string[] = [];
      // ... 组装埋点数据
      break;

    // ========== 情况3: 价格区间 ==========
    case QuickFilterItem.PRICE_RANGE:
      // 更新 selectedMap
      _selectedMap.set(
        "priceRange",
        priceValue?.map?.(item => String(item)) ?? []
      );
      setSelectedMap(_selectedMap);

      // 合并多个数据源
      const mergedMap = mergeMaps(
        getDropDownSelectInfoMap(),  // 车型、人数、城市等
        _selectedMap                 // 价格
      );

      // 转换为字符串格式
      const priceSelectedStr = selectedItemsParseReverseFilter(
        mergedMap, minPrice, maxPrice
      );

      // 通知父组件
      onFilterSelectedItemsChanged(priceSelectedStr);

      // 组装埋点
      _select_count = 2;
      _select_content = `价格范围_${priceValue.join("-")}`;
      break;

    // ========== 情况4: 通用筛选项 ==========
    default:
      // 更新通用筛选项字符串
      let selectedItemsNew = updateSelectedItems(
        quickFilterOptions,
        tabIndex,
        filterSelectedItems,
        getCommonGroupType(quickFilterOptions, tabIndex),
        selectedItemInner
      );

      if (selectedItemsNew !== filterSelectedItems) {
        onFilterSelectedItemsChanged(selectedItemsNew);
      }

      // 组装埋点
      _select_content = selectedItemInner
        ?.map?.(item => {
          const currentOption = quickFilterOptions?.[tabIndex];
          return (
            currentOption?.sortItemName +
            "_" +
            currentOption?.sortItemModeList?.[item]?.name
          );
        })
        ?.join?.(",");
      break;
  }

  // ========== 记录埋点 ==========
  if (lxParams?.cid && lxParams?.confirmMCBid) {
    lx.lxModuleClick({
      cid: lxParams.cid,
      pageInfoKey: lxParams.pageInfoKey,
      channelName: lxParams.channelName,
      bid: lxParams.confirmMCBid,
      param: {
        poi_id: poiId || "-999",
        select_count: _select_count,
        select_content: _select_content,
        product_type: lxParams?.product_type || "-999",
        module_source: lxParams?.module_source || "-999",
        ...(lxParams?.itemParams || {}),
      },
    });
  }

  // ========== 关闭面板 ==========
  props.onPanelClose?.("confirm");
  setShowModalVisible(false);
};

架构	分层设计，DropDownPanel 是筛选面板的容器，内部根据 contentType 选择具体的筛选组件

渲染逻辑	根据 contentType（当前打开的筛选项类型）进行条件渲染
核心特点	支持新旧筛选项并存、精细的状态恢复、智能的清空机制、完整的埋点体系
