# 一、对象的规则设置
### 1.冻结
#### Object.freeze()
当组件接受props是不能直接修改的比如：
```
export default function FunctionDemo(props) {
  props.obj=5
}
```
因为传进的属性被冻结了，所以不能修改，
React做了Object.freeze(props)
被冻结的属性不能`增删改、劫持`

### 2.密封
#### Object.seal()
同理被密封的属性不能进行`增、删、劫持`
但是可以改动

### 3.不可扩展
#### Object.preventExtensions()
被设置为不可扩展的对象，不能`新增属性`

## 被冻结的对象同时也被密封和不可扩展，被密封的对象同时也不可扩展
