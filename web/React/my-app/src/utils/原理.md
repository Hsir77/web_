# 一、原理
### 从react中jsx语法--->real dom 的过程中经历以下几个步骤
### 1、
jsx通过bable把语法糖从
``` render(<div className="container">111</div>) ```
变为 react最初始语法
``` 
React.createElement(
    'div', 
    { className: 'container' }, 
    '111' 
);
 ```
二者都会经过 ReactDom.render(变量, document.getElementById('root')) 挂载到页面上并渲染
### 2、
React.createElement 函数会把初始的react形式转为虚拟dom对象 用于react构建真实dom

构建原理：[createElement](./handleJsx.js)函数
将传入的属性提取、构造成virtual dom的形式
### 3、
virtual dom最终经过`ReactDom.render()`，ReactDom.render会找到挂载点`document.getElementById('root')`，再递归遍历虚拟dom，调用浏览器原生api创建真实dom
如果虚拟dom变化，会进行diff展出最小差异，更新页面
