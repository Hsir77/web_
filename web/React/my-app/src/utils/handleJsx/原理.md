# 一、原理
### 从react中jsx语法--->real dom 的过程中经历以下几个步骤
### 1、
jsx通过bable把语法糖从
``` render(<div className="container">111</div>) ```
变为 react最初始语法
``` 
React.createElement(
    'div', 
    { className: 'container' }, 
    '111' 
);
 ```
二者都会经过 ReactDom.render(变量, document.getElementById('root')) 挂载到页面上并渲染
### 2、
React.createElement 函数会把初始的react形式转为虚拟dom对象 用于react构建真实dom

构建原理：[createElement](./handleJsx.js)函数
将传入的属性提取、构造成virtual dom的形式
### 3、
virtual dom最终经过`ReactDom.render()`或`createRoot(document.getElementById('root')).render`，ReactDom.render会找到挂载点`document.getElementById('root')`，再递归遍历虚拟dom，调用浏览器原生api创建真实dom
如果虚拟dom变化，会进行diff展出最小差异，更新页面


# 二、递归遍历虚拟dom

### 1、
对于对象的属性来说，分为公有、私有和可枚举、不可枚举等属性，`公有私有用于控制是否可访问`,`可枚举不可枚举用于控制是否可遍历`
比如for in只能遍历公有可枚举属性，而object.defindProperty可以修改属性为不可枚举，遍历虚拟dom时需要区别上面四种属性
对于原型，内置方法属于不可枚举，而自定义属于可枚举 

### 2、
`Object.getOwnPropertyNames()`可以获取非symbol的所有属性
`Object.getOwnPropertySymbols()`可以获取所有symbol属性
具体实现原理：[traverse](./handleJsx.js)函数
